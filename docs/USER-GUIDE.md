# EmbeddingGemma 2 使用指南

面向第一次使用的同事。目标：**3 分钟完成第一次检索**，并且知道结果不好时该调什么。

> 应用内也有一份同样的内容：顶部「帮助」按钮、菜单「帮助 › 帮助中心」或按 `F1` 打开。
> 本文是仓库里的离线副本，便于打印或随包分发。

## 2. 三分钟上手

1. **放资料**
   把文件拖进左侧上传区，或按 `Ctrl+O` / 菜单「文件 › 上传文档」。
   支持 `md` / `txt` / `csv` / `json` / `log`、常见代码文件、带文字层的 PDF；单个文件 ≤ 25 MB。
   上传后会自动抽取文本、切块（约 900 字符/块）并生成本地向量。

2. **选模式**
   默认「文档检索」适合问答。找代码切「代码检索」，比较两段话用「语义相似」。
   不知道选哪个就用默认模式。

3. **提问**
   按 `/` 聚焦搜索框，输入一句完整的问题，回车。
   例如「企业账号忘记密码时，管理员应该怎么重置？」而不是「密码 忘记」。

4. **看结果**
   先看 Top 3 的内容，不只看分数。需要收窄范围时点结果卡上的「只看该文档」；需要原文时点「复制」或「展开全文」。

## 3. 最佳实践

### 3.1 上传什么

**推荐**

- 单一主题、信息密度高的文档；一个文件讲清一件事。
- 制度、FAQ、手册、接口说明、设计笔记、代码文件。
- 文档更新后：先删除旧版本，再上传新版本。

**避免**

- 整本手册、会议记录、目录页、重复内容一次性塞入。
- 同一文件重复上传（会产生重复块，挤占返回名额）。
- 扫描版 / 图片型 PDF（没有文字层，无法切块；需先 OCR）。

### 3.2 怎么提问

把提问写成一句完整的话，带上场景和限定词：

| 不推荐 | 推荐 |
|---|---|
| 密码 | 企业账号忘记密码时，管理员应该怎么重置？ |
| 限流 | 网关的 token bucket 限流是怎么实现的？ |
| 发票 开票 | 企业版发票什么时候可以开，需要哪些信息？ |

一次只问一个问题。复合问题拆开检索，命中率更高。

### 3.3 怎么读分数

余弦相似度不是概率，不同语料的分布也不同：

| 分数 | 含义 |
|---|---|
| ≥ 0.70 | 强相关，通常可以直接引用 |
| 0.55 – 0.70 | 可能相关，结合上下文判断 |
| 0.40 – 0.55 | 弱相关，只作线索 |
| < 0.40 | 基本无关，优先换问法 |

**先看 Top 3 的相对排序，再看绝对值。**

### 3.4 维护习惯

- 单机建议控制在 10 万块以内（约 300 MB 内存），更多时改用 sqlite-vec / FAISS。
- 定期删除不再需要的文档；删除会同时移除对应向量。
- 备份：关闭应用后复制整个 `data` 目录（内含 `app.db`）。

## 4. 模式与参数

### 文档检索（search result，默认）

把提问包装成检索任务，适合 FAQ、制度、手册、技术文档。
示例：`忘记密码怎么处理？`

### 代码检索（code retrieval）

用自然语言在代码库里找实现，适合「某个功能是怎么做的」。
示例：`token bucket 限流怎么实现`

### 语义相似（sentence similarity）

拿一段话去找相似段落，适合查重、找相关案例、归并同义问题。
示例：`用户无法登录，提示凭据无效`

### 返回条数（top_k）

- `3–5`：问题明确、只想看最相关的几条。
- `8`：默认值。
- `12–20`：第一次探索、问题较宽泛，先看全貌再收窄。

### 向量维度（MRL）

`768` 最准；`512 / 256 / 128` 会截断向量，计算更快但召回略降。日常保持 `768`。

## 5. 键盘快捷键

| 快捷键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `Enter` | 执行检索 |
| `Esc` | 先关闭帮助中心；没有弹层时清空检索条件 |
| `F1` | 打开帮助中心 |
| `Ctrl` + `/` | 打开快捷键说明 |
| `Ctrl` + `O` | 上传文档（桌面版） |
| `Ctrl` + `R` | 刷新界面（桌面版） |
| `Ctrl` + `+ / -` | 放大 / 缩小（桌面版） |
| `F11` | 全屏（桌面版） |

macOS 上把 `Ctrl` 换成 `⌘`。

## 6. 软件信息与数据位置

菜单「帮助 › 软件信息」或帮助中心的「软件信息」页会显示：

- 版本、运行形态（桌面版 / 浏览器版）、平台与架构
- Electron / Chromium / Node.js 版本
- 模型名称、量化、上下文长度、向量维度
- 文档数、块数、推理状态
- 数据目录、日志目录、模型文件、推理运行时
- 「复制诊断信息」按钮

**数据目录**：默认在用户数据目录下的 `data/app.db`（SQLite）。
**日志**：数据目录下的 `logs/`；启动器日志在 `%TEMP%\embeddinggemma2-startup.log`。

## 7. 常见问题

### 顶部显示「模型离线 / 连不上后端」

推理进程还没就绪。依次：等待十几秒 → 重开应用 → 打开日志目录查看 `llama-server.log` → 检查杀软是否拦截 `llama-server.exe`。

### 上传成功但检索没有命中

1. 看左侧文档的「块数」是否 > 0。
2. 换一句更完整的话。
3. 返回条数调到 `12–20`。
4. 确认模式正确（找代码用「代码检索」）。
5. 用「只看该文档」缩小范围。

### PDF 提示「没有可提取的文字」

扫描件 / 图片型 PDF 没有文字层。先 OCR，再上传识别后的文件。

### 双击没反应 / 启动即退出

查看 `%TEMP%\embeddinggemma2-startup.log` 与 `embeddinggemma2-launcher.log`。常见原因是目录不可写或被杀软拦截；启动器会自动重试并切换到可写目录。

### 会不会联网 / 上传数据

不会。模型与向量库都在本机，服务只监听 `127.0.0.1`。唯一可能联网的场景是轻量包首次启动时下载模型。
